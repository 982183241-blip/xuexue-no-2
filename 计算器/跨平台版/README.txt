计算器 1.0.3（跨平台版）

Windows 和 macOS 均可运行。需要安装带 Tkinter 的 Python 3，建议从 python.org 下载安装。
Windows 安装时可勾选 Add python.exe to PATH。解压后在文件夹中打开终端，运行：
    py calculator.py

macOS 解压后在文件夹中打开终端，运行：
    python3 calculator.py

启动后会显示独立桌面窗口。支持点击按键和键盘输入。
Enter 计算结果，Esc 清空，Backspace 退格。
连续运算按输入顺序计算。

开发协作时，双方从压缩包中的 calculator.py 开始修改，并保留一份原始文件作为合并基准。

点击左上角「设置」可切换主题，程序会记住上次选择。
